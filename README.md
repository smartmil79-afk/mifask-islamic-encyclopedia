# Mifask Islamic Encyclopedia
Developed by Fixable 6Tems Limited.

A responsive Next.js starter for a comprehensive Islamic knowledge platform.

## Included in this starter
- Homepage and Mifask branding
- Responsive navigation and mobile menu
- Theme toggle (light/dark)
- Explore page with search
- Category pages
- Article reading pages
- Starter content and reference placeholders
- About and Sources & Methodology pages
- Arabic display and RTL support

## Run locally
1. Install Node.js 20 or newer.
2. In the project folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open http://localhost:3000

## Deploy
Push to GitHub and import the repository into Vercel. No environment variables are needed for this starter.
